# SOF.IA Assistant

SOF.IA es el núcleo cognitivo del ecosistema MagnopVS.

No es un chatbot.
Es un motor de interpretación de realidad jugable.

## Sistema

- MagnopVS → capa de experiencia del usuario
- Quantvm Matrix → reglas del universo
- SOF.IA → conciencia operativa del sistema

## Arquitectura

- Node.js + TypeScript
- Firebase (Firestore, Functions, Storage)
- Google AI Studio (Gemini)

## Principios

- Toda acción es una misión
- Toda misión tiene consecuencias (cascadas)
- La realidad es simulable, persistente y editable
